## 必须交付

1. 实质结合 **PayPal Sandbox 与 AI** 的可运行作品，PayPal 集成须是核心能力；可新建，也可在赛事期间显著推进已有项目。
2. 功能说明，以及模型／AI 工具如何参与作品的说明。
3. 评委能运行或交互的版本：完整安装运行说明，或托管演示；静态设计稿不满足要求。
4. **公开、开源的代码仓库**，包含运行所需源码、资产、说明和可识别的许可证。
5. **少于 3 分钟、公开可见的 YouTube 演示视频**，展示实际运行。

来源：[主页 Requirements](https://paypalaihackathon.devpost.com/)。无指定赛题；赞助商工具可选。

规则 §4–§5 另要求：材料为英文或附英文翻译；已有项目说明本次增量；遵守第三方素材和依赖许可；免费测试访问持续至评审结束，需登录或特殊权限时提供测试账号或明确的访问获取方式；截止后修改正式提交受到限制。详见 [Official Rules](https://paypalaihackathon.devpost.com/rules)。测试访问建议通过受控方式交付，不在公开仓库放真实密钥。

## 评审与奖项

- 五项等权：技术实现、设计、潜在影响、创新、演示表达（Rules §6）。
- 主奖依次为 $12,000、$8,000、$5,000；另有特别奖和赞助奖。
- 官网现金合计 $67,500；加入 $2,250 Render credits 后为 $69,750，并非全部现金。
- FAQ 限制单项目的奖项叠加：最多一个主奖或特别奖，再加一个赞助奖。

来源：[主页 Prizes / Judging Criteria](https://paypalaihackathon.devpost.com/)、[FAQ](https://paypalaihackathon.devpost.com/details/faqs)、[规则 §6](https://paypalaihackathon.devpost.com/rules)。
