# 当前产品方向

更新日期：2026-10-29（Europe/London）。用户已认可**通用票据整理与报销助手**方向，并要求先审阅产品设计、MVP 范围与开发计划。详细方案仍待评审，本轮不开始应用实现。

## 已确定的方向

组织配置报销规则；报销人提交票据和用途；AI 提取内容并指出疑点，程序根据明确规则分流为自动批准、请求补交或人工审核；通过审批的申请由 PayPal Sandbox Payouts 付款，并跟踪单笔付款结果。

AI 使用 API Key 从服务端接入。供应商、模型和费用预算待选择；本轮不索取、保存或使用真实密钥。
